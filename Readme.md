# Customer Churn Prediction

## Project Overview

This project predicts whether a telecom customer is likely to leave the company (churn) using Machine Learning.

The model helps telecom companies identify customers who may leave and take proactive retention actions.

---

## Business Problem

Customer retention is one of the biggest challenges in the telecom industry.

This project predicts customer churn using historical customer data.

---

## Dataset

Dataset used:

Telco Customer Churn Dataset from Kaggle

https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Dataset file:

WA_Fn-UseC_-Telco-Customer-Churn.csv

---

## Machine Learning Model

Algorithm used:
